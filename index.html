Connect your Google Drive

Your receipts are saved in your own Google Drive. To allow that, this app needs a free Google "Client ID". You only set this up once.

How to get your Client ID (about 10 minutes)
  1. On your laptop, go to console.cloud.google.com and sign in with oyendetomi@gmail.com. Create a project called Tomi's Shoebox.
  2. Open Google Drive API and click Enable.
  3. Open Google Auth Platform and click Get started. App name: Tomi's Shoebox. Audience: External. Use your email for the contact fields, then finish.
  4. Go to Audience, then under Test users add oyendetomi@gmail.com.
  5. Go to Clients, then Create client. Type: Web application. Under Authorized JavaScript origins add this app's address. Under Authorized redirect URIs add the same address followed by /. Click Create.
  6. Copy the Client ID (it ends in .apps.googleusercontent.com) and paste it below.

When Google says it hasn't verified this app, that's expected: it's your own private app. Tap Continue.

Install Shoebox so it opens like a normal app.
